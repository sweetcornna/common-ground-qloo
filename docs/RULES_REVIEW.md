# Competition review

Reviewed 8 October 2026. Recheck the official pages before submitting; this record does not determine eligibility.

The [event overview](https://qloo.devpost.com/) requires a working Qloo-powered agentic application, a functional external demo, a public source repository, an open-source license and a project description. A local-only or private demonstration does not meet its published-demo requirement. A video is optional. Common Ground uses LangGraph and Qloo as its intended live recommendation source; implementation alone does not establish compliance before live validation and release.

The [official rules](https://qloo.devpost.com/rules) set the deadline at 30 October 2026, 11:45 p.m. Eastern: **31 October 2026, 03:45 UTC / 11:45 Beijing**. Judging ends 16 November 2026, 11:45 p.m. Eastern (EST), or 17 November 2026, 12:45 Beijing. Keep judge access working through that period. Submission materials must be in English or accompanied by an English translation.

The rules permit third-party technical assistance while requiring the entrant's ideas, creativity, ownership and respect for third-party rights. They do not explicitly settle AI-assisted development. Substantial AI implementation is disclosed; the entrant must review rights and any organizer clarification before making submission representations. Eligibility, geographic restrictions, conflicts, authorized team representation and third-party licenses remain the entrant's responsibility.

The [official resources page](https://qloo.devpost.com/resources) has a verified API-key application link. The project's application was submitted separately in the parent task and is awaiting organizer approval; no key has been received or tested. The [developer guide linked by the rules](https://docs.qloo.com/reference/qloo-llm-hackathon-developer-guide#getting-your-api-key) is a secondary reference whose main host was inaccessible from the build environment. No approval timeline is guaranteed.
